## O que há aqui

| Ficheiro | O que é |
|---|---|
| `index.html`, `site.css`, `site.js` | Página interativa: um qubit que se pode medir e um circuito em que cada porta é uma cadeira ou um projeto. |
| `CV_Rodrigo_Cerejo_PT.html`, `CV_Rodrigo_Cerejo_EN.html` | O CV de uma página A4, de onde saem os PDF. |

Tudo em HTML, CSS e JavaScript, sem frameworks nem passo de build.

## Exportar o PDF

Abrir `CV_Rodrigo_Cerejo_PT.html` no Chrome ou no Edge, imprimir para PDF em A4, sem margens e com os gráficos de fundo ligados.
